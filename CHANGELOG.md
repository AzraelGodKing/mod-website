# Changelog

## Unreleased

- 7 Days to Die mod pages list each mod's chat and console commands, grouped by who uses them, with admin-only ones marked: Zombie and Animal Bait, Bait UI, Blood Moon Sound, Drone Loot Filter, Keep Backpacks, Remove Any Entity, Spawn Tuner, and Speedometer. The commands live in `src/data/sevendays-commands.json` and were checked against each mod's source in 7d2d_mods.
- 7 Days to Die mod pages no longer repeat the other 7 Days to Die mods at the bottom. The back link to the full list stays.
- 7 Days to Die mods can be marked "Server, client optional" when the server part works alone and players can add the client part, with its own filter chip. Blood Moon Sound uses it: players get the sounds and countdown, and the server can post Discord and chat alerts, without needing each other.
- The 7 Days to Die page is a compact, sortable list instead of large cards. Each row shows a one-line summary, a type (Fixes, Server admin, Crafting, Gameplay, HUD & sound), where it installs (server only, client only, or both), version, update date, Nexus downloads, and a Download button. Search matches every word, chips filter by type and install side, and the list sorts by name, recently updated, most downloaded, or type, from the dropdown or the column headers. The search, filters, and sort stay in the URL so a filtered list can be shared, and `/` jumps to the search box. Summaries, types, and install sides live in `src/data/sevendays-index.ts`; a new mod without an entry gets its install side from its description.
- Download buttons always give the newest zip. They point at `/download/<game>/<mod>`, which the Worker answers with the latest version in `downloads.json` (cached five minutes), so a mod release reaches the site without a rebuild or deploy. Mod pages and game hubs also swap in the newer version, zip name, and upload date from `/api/downloads`.
- A `mod.json` that is not a catalog entry (the XML one inside 7 Days Bait's shipped folder) is skipped, and one saved with a byte order mark (Gyro Safe) loads. Either had stopped every catalog build.
- A new mod without its own Linear label no longer stops the Worker. Its reports carry the game and website labels. Craftable Signs, Drone Loot Filter, Gyro Safe, No Ding Sound, Slot Lock Fix, Spawn Tuner, Zombie and Animal Bait, and Bait UI need labels in `report-labels.json`.
- RimWorld pages and downloads use the current hosted versions: Date Night 1.7.2, Deep Colony 1.10.0, Homesteader 1.5.1, Nemesis 1.5.0, Niceties 1.6.1, Stormproof 1.7.0, and Strata 3.11.0. RimWorld badges say 1.6 and 1.7. A leftover version chip such as Strata 3.5 is not shown beside the current version.
- Each mod page shows when its download was uploaded ("Updated Oct 11, 2026") under the version. The date comes from `downloads.json`, or from the zip itself when the site finds a newer one in the bucket (AZR-455).
- A mod whose newer zip is already on `downloads.azraelsmods.com` links that zip even when `downloads.json` lost its entry. Releasing several mods at once had left 16 mods on older downloads (AZR-453).
- Remove Any Entity replaces Remove Zombie Dogs / Remove Entities on the 7 Days to Die catalog and links its Nexus page (12841). The separate Remove Zombie Dogs page, theme, and report label are gone, and the guide tells players to delete the old `RemoveZombieDogs` folder.
- A scheduled Buildkite build of `main` rebuilds the catalog from the mod repos and deploys when a mod release changed it, so new versions reach the site without a merge here. The build publishes `/catalog-version.txt` to compare against (AZR-454).

- Each RimWorld mod page uses that mod's colors and explains what it does: overview, feature groups, and what to know before you install.
- Each Sun Haven mod page does the same: that mod's colors, what it does, and which other mods it pairs with.
- Each 7 Days to Die mod page does the same, in the night-board look: that mod's colors, what it does, and whether it goes on the server, the player, or both.
- Each mod page links the latest zip recorded in `downloads.json` on `downloads.azraelsmods.com`. Blood Moon Sound is 1.2.1, Keep Backpacks is 1.2.1, and Remove Any Entity is on the 7 Days to Die catalog.
- Honk Door Fix is on the 7 Days to Die catalog and links its Nexus page. A report from that page uses the Honk Door Fix label.
- Craft From Chests and Upgrade Bench downloads are on `downloads.azraelsmods.com`.
- 7 Days to Die mods link their Nexus pages, so the hourly counter can read those download counts. Craft From Chests and Upgrade Bench are on the catalog.
- `/admin` shows every download counter, when it last refreshed, and when the next hourly refresh runs. Refresh now fetches the stores right away without moving the hourly schedule. The page needs the `ADMIN_TOKEN` Worker secret.
- Download counters are back. The homepage, game pages, and mod pages show Steam subscribers and Nexus downloads for RimWorld, Thunderstore and Nexus downloads with a combined total for Sun Haven, and Nexus downloads for 7 Days to Die. The Worker refreshes them every hour and keeps the last good count when a store does not answer.

- Game names in the header stay light on the bar, including links already opened.
