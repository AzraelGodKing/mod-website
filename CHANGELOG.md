# Changelog

## Unreleased

- Link previews and search: every page has a canonical URL and OpenGraph/Twitter tags, and mod pages use their preview as the share image (large card for posters, small card for square icons). Titles read "Mod · Game · Azrael's Mods", and game pages get a real description naming the stores they sit alongside. `/sitemap.xml` lists the home page, the three catalogs, and every mod page with its upload date, and `/robots.txt` points at it and keeps crawlers off `/admin`, `/api/`, `/download/`, and `/not-ready`.
- The mod lists load a small WebP thumbnail per row (240x150, or 96x96 for square icons) instead of the full poster, about 130 KB instead of 1.4 MB on the 7 Days to Die page. `collect-mods.mjs` makes them with `sharp`, now a dev dependency, and falls back to the full image without it. List thumbnails and mod page posters carry width and height, so the page no longer jumps as they load.
- Google Fonts load from a stylesheet link with preconnect in the page head instead of a CSS `@import`, so the page no longer waits on a second round trip before it can draw.
- A "Skip to content" link appears on the first Tab. The "What it does" tabs on mod pages follow arrow keys, Home, and End, and tabs and panels are linked for screen readers. The Turnstile script for "Report a problem" loads only when the form comes near the screen or gets focus.
- Every page except `/admin` has a footer with the three GitHub repos and a pointer to "Report a problem". The 404 and "Not ready" pages link back to each catalog and stay out of search results. Phones color the browser bar to match each page's header.
- Craftable Canvas Signs, Drone Loot Filter, Gyro Safe, No Ding Sound, Slot Lock Fix, Spawn Tuner, Zombie and Animal Bait, and Bait UI have their own Linear labels in `report-labels.json`, so their reports are labelled by mod.

- `/admin` is redesigned in the site's dark gold look and split into tabs. Overview has total, site, and Steam tiles, a card per game with its top mod, a Health list (D1, Nexus API key, password sign-in, passkeys, `downloads.json`, releases), and shortcuts to Cloudflare, the APIs, and the repos. Downloads has search, game filters, sortable columns, and the top mod in each column highlighted. Releases compares each page's build version with `downloads.json` and flags mods missing from it or behind it, with a count on the tab. Activity lists this site's Download clicks per mod and version with the last click time. Sign-in holds passkeys, the active session count, and Sign out everywhere. Export CSV downloads every counter. New signed-in routes: `GET /api/admin/releases`, `GET /api/admin/site-downloads`, `GET /api/admin/overview`, `POST /api/admin/sessions/clear`.
- `/admin` signs in with a passkey (WebAuthn), such as one saved in LastPass. Sign in with the `ADMIN_TOKEN` password once, then use Add passkey under Passkeys; after that, Sign in with a passkey works on azraelsmods.com and www. Passkeys, one-time challenges, and 12-hour sessions live in the `DOWNLOADS_DB` D1 database (tables `admin_passkeys`, `admin_challenges`, `admin_sessions`, created on first use). Either sign-in sets an HttpOnly, SameSite=Strict session cookie, so the page no longer keeps the password in sessionStorage, and admin writes from another origin are refused. Removing `ADMIN_TOKEN` turns password sign-in off; the last passkey cannot be removed while it is unset. Scripts can still send `Authorization: Bearer <ADMIN_TOKEN>`. Uses `@simplewebauthn/server`.
- The site counts its own downloads. Every Download button goes through `/download/<game>/<mod>`, and the Worker now adds one to that mod and version in a D1 table (`DOWNLOADS_DB`, database `azraels-mods-downloads`) before it redirects, without making the redirect wait. Link previews and crawlers (Discord, Google, Facebook and the like) are not counted, and the redirect is no longer cached so every click reaches the Worker. Wrangler creates the database on the first deploy and the Worker creates its table on first use.
- `/api/stats` adds each mod's `site` count and each game's `site` and `total` (site + Thunderstore + Nexus; Steam subscribers stay separate). The Downloads column on all three game pages is that total, and mod pages list Downloads, This site, and each store. `/admin` shows the site and total columns.
- The RimWorld and Sun Haven pages use the same compact, sortable list as 7 Days to Die instead of large cards, each in its own colors. Rows show a one-line summary, a type, version, update date, store count (Steam subscribers for RimWorld, Thunderstore + Nexus downloads for Sun Haven), and a Download button. RimWorld types are Base, Colonists, Events, QoL, and Storyteller; Sun Haven keeps its QoL, Storage, UI, Social, Tracking, Skills, and Dev groups. Both open in featured order and can sort by name, update date, count, or type. RimWorld rows keep a small poster. Summaries, types, and order live in `src/data/hub-index.ts`, and all three lists share `src/components/ModList.astro`.
- RimWorld and Sun Haven mod pages get the same Details panel as 7 Days to Die (type, version, updated, each store's count, file) and a back link to the full list, and no longer repeat the other mods at the bottom.
- 7 Days to Die mod pages list each mod's chat and console commands, grouped by who uses them, with admin-only ones marked: Zombie and Animal Bait, Bait UI, Blood Moon Sound, Drone Loot Filter, Keep Backpacks, Remove Any Entity, Spawn Tuner, and Speedometer. The commands live in `src/data/sevendays-commands.json` and were checked against each mod's source in 7d2d_mods.
- 7 Days to Die mod pages no longer repeat the other 7 Days to Die mods at the bottom. The back link to the full list stays.
- 7 Days to Die mods can be marked "Server, client optional" when the server part works alone and players can add the client part, with its own filter chip. Blood Moon Sound uses it: players get the sounds and countdown, and the server can post Discord and chat alerts, without needing each other.
- The 7 Days to Die page is a compact, sortable list instead of large cards. Each row shows a one-line summary, a type (Fixes, Server admin, Crafting, Gameplay, HUD & sound), where it installs (server only, client only, or both), version, update date, Nexus downloads, and a Download button. Search matches every word, chips filter by type and install side, and the list sorts by name, recently updated, most downloaded, or type, from the dropdown or the column headers. The search, filters, and sort stay in the URL so a filtered list can be shared, and `/` jumps to the search box. Summaries, types, and install sides live in `src/data/sevendays-index.ts`; a new mod without an entry gets its install side from its description.
- Download buttons always give the newest zip. They point at `/download/<game>/<mod>`, which the Worker answers with the latest version in `downloads.json` (cached five minutes), so a mod release reaches the site without a rebuild or deploy. Mod pages and game hubs also swap in the newer version, zip name, and upload date from `/api/downloads`.
- A `mod.json` that is not a catalog entry (the XML one inside 7 Days Bait's shipped folder) is skipped, and one saved with a byte order mark (Gyro Safe) loads. Either had stopped every catalog build.
- A new mod without its own Linear label no longer stops the Worker. Its reports carry the game and website labels. Craftable Signs, Drone Loot Filter, Gyro Safe, No Ding Sound, Slot Lock Fix, Spawn Tuner, Zombie and Animal Bait, and Bait UI need labels in `report-labels.json`.
- RimWorld pages and downloads use the current hosted versions: Date Night 1.7.2, Deep Colony 1.10.0, Homesteader 1.5.1, Nemesis 1.5.0, Niceties 1.6.1, Stormproof 1.7.0, and Strata 3.11.0. RimWorld badges say 1.6 and 1.7. A leftover version chip such as Strata 3.5 is not shown beside the current version.
- Each mod page shows when its download was uploaded ("Updated Oct 11, 2026") under the version. The date comes from `downloads.json`, or from the zip itself when the site finds a newer one in the bucket (AZR-455).
- A mod whose newer zip is already on `downloads.azraelsmods.com` links that zip even when `downloads.json` lost its entry. Releasing several mods at once had left 16 mods on older downloads (AZR-453).
- Remove Any Entity replaces Remove Zombie Dogs / Remove Entities on the 7 Days to Die catalog and links its Nexus page (12841). The separate Remove Zombie Dogs page, theme, and report label are gone, and the guide tells players to delete the old `RemoveZombieDogs` folder.
- A scheduled Buildkite build of `main` rebuilds the catalog from the mod repos and deploys when a mod release changed it, so new versions reach the site without a merge here. The build publishes `/catalog-version.txt` to compare against (AZR-454).
